# 06. USER ROLES & PERMISSIONS — VARAHI GIRLS HOSTEL

## 1. Role-Based Access Control (RBAC) Architecture

Security and operational governance across the 5 DEVI Hostels branches are controlled via 5 granular roles implemented via Supabase Row-Level Security (RLS) and Next.js middleware guards.

---

## 2. Defined Roles

### 2.1 Role 1: OWNER / SUPER ADMIN (E. BHARATH CHANDRA)
- **Scope:** Global (All 5 Branches).
- **Permissions:**
  - Full read/write authority across all branches, rooms, and beds.
  - Complete financial dashboard access (gross revenues, online gateway, cash/UPI collections, advance liabilities, deposit liabilities).
  - Staff user management (invite, deactivate, assign branch managers, accountants, wardens).
  - Final approval on security deposit refunds and fee waivers.
  - Full audit log inspection.
  - System configuration and pricing rules.

### 2.2 Role 2: BRANCH MANAGER
- **Scope:** Scoped strictly to assigned `branch_id`.
- **Permissions:**
  - Review admission enquiries filtered for their branch.
  - Confirm admission and execute bed allocation.
  - Manage floor and room availability within the branch.
  - Record offline fee collections (subject to accountant verification).
  - Generate branch-specific occupancy and pending dues reports.

### 2.3 Role 3: ACCOUNTANT
- **Scope:** Multi-branch financial ledger access.
- **Permissions:**
  - Generate recurring monthly invoices and ad-hoc utility/maintenance charges.
  - Verify offline cash receipts and direct UPI transactions against bank credits.
  - Manage Advance Rent credits and Security Deposit ledgers.
  - Issue official digital payment receipts.
  - Export monthly collection and outstanding dues balance sheets.

### 2.4 Role 4: WARDEN
- **Scope:** Branch-specific operational day-to-day oversight.
- **Permissions:**
  - Access resident directory and emergency contact numbers.
  - Execute resident check-in and check-out workflows.
  - Log and resolve resident complaints and maintenance tickets.
  - Maintain visitor registry and night curfew / shift logs.
  - Post branch notice board announcements.

### 2.5 Role 5: RESIDENT
- **Scope:** Self-service personal profile only (`auth.uid() = resident.profile_id`).
- **Permissions:**
  - View personal DEVI Resident ID and current room/bed allocation.
  - Inspect current outstanding rent, advance balance, and security deposit.
  - Download monthly invoices and payment receipts.
  - Make online rent payments via integrated gateway (Razorpay/Cashfree).
  - Submit maintenance requests / complaints and track resolution.
  - Receive automated notifications and view hostel notices.
