# 09. PAYMENT GATEWAY INTEGRATION — VARAHI GIRLS HOSTEL

## 1. Gateway Specifications

DEVI Hostels supports dual primary payment gateway options for Indian domestic transactions:
- **Primary:** Razorpay API v1
- **Secondary / Failover:** Cashfree PG v2

Both integrations support **Instant UPI (Google Pay, PhonePe, Paytm, CRED)**, Domestic RuPay/Visa/Mastercard Credit & Debit Cards, and Net Banking across 50+ Indian banks.

---

## 2. Server-Side Payment Architecture

Frontend redirects are treated strictly as UI indicators; **no financial transaction is marked paid based on client redirect alone.**

```
[Resident Browser]                    [Next.js Server]                     [Razorpay / Bank]
       |                                      |                                    |
       |--- 1. Click "Pay ₹7,000" ---------->|                                    |
       |                                      |--- 2. Create Order (server-to-server) ->|
       |                                      |<-- 3. Return order_id & signature --|
       |<-- 4. Open Razorpay Checkout Sheet --|                                    |
       |                                                                           |
       |--- 5. Resident Completes Payment (UPI / Card) --------------------------->|
       |                                                                           |
       |                                      |<-- 6. Webhook / Verify Callback ---|
       |                                      |    (HMAC-SHA256 Signature Verify)  |
       |                                      |--- 7. Idempotent DB Commit:        |
       |                                      |       - Record `payments` row      |
       |                                      |       - Decrement balance_due      |
       |                                      |       - Generate Digital Receipt   |
       |<-- 8. Instant UI Confirmation -------|                                    |
```

## 3. Implemented Routes & Endpoints

### 3.1 Order Generation (`/api/payments/razorpay/order`)
- Validates resident ID, invoice ID, and payment amount.
- In production, calls Razorpay Orders API:
  `razorpay.orders.create({ amount: amountInPaise, currency: 'INR', receipt: invoice_number, notes: { devi_resident_id } })`.
- In development/sandbox mode, generates cryptographically secure mock order IDs (`order_devi_[TIMESTAMP]_[RAND]`).

### 3.2 Payment Verification & Ledger Settlement (`/api/payments/razorpay/verify`)
- Cryptographic HMAC-SHA256 signature verification:
  `crypto.createHmac('sha256', secret).update(`${razorpay_order_id}|${razorpay_payment_id}`).digest('hex')`.
- In-memory & DB idempotency protection against duplicate network deliveries.
- Automatically invokes `recordPayment()`, marking invoice paid or partially paid, routing excess to advance rent credit, and issuing a permanent digital receipt.

### 3.3 Resident Portal Checkout (`/resident/invoices`)
- Modal allows residents to pay online instantly using UPI, Cards, or Net Banking.
- Communicates directly with `/api/payments/razorpay/order` and `/api/payments/razorpay/verify`.
- Real-time receipt confirmation and balance refresh.
