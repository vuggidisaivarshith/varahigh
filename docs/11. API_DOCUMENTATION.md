# 11. API DOCUMENTATION — VARAHI GIRLS HOSTEL

## 1. Overview & Authentication Standard

DEVI Hostels provides RESTful Next.js Route Handlers (`src/app/api/...`) secured by Supabase JWT session headers, API bearer keys, or signed webhook HMAC signatures.

---

## 2. Phase 1 Core Endpoints

### 2.1 Public Admission Enquiries

#### `POST /api/enquiries`
Submits a public admission enquiry from the multi-step form.
- **Access:** Public (Rate-limited by IP).
- **Request Body:**
  ```json
  {
    "category": "student" | "airport_employee",
    "full_name": "Karthik Sharma",
    "phone": "9876543210",
    "email": "karthik@example.com",
    "gender": "male",
    "emergency_contact_name": "Ramesh Sharma",
    "emergency_contact_phone": "9876543211",
    "emergency_contact_relation": "Father",
    "preferred_branch_id": "uuid",
    "room_sharing_preference": "2_sharing",
    "expected_joining_date": "2026-12-01",
    "student_college_name": "Vardhaman College of Engineering",
    "student_course": "B.Tech CSE",
    "student_year": "2nd Year",
    "student_parent_phone": "9876543211"
  }
  ```
- **Response (201 Created):**
  ```json
  {
    "success": true,
    "message": "Enquiry submitted successfully. DEVI Hostels management will contact you shortly.",
    "enquiry_id": "uuid"
  }
  ```

### 2.2 Admin Enquiry Management

#### `GET /api/admin/enquiries`
Fetches paginated enquiries with branch and status filtering.
- **Access:** Authenticated Staff (`owner`, `branch_manager`, `accountant`, `warden`).
- **Query Parameters:** `branch_id`, `status`, `category`, `search`, `page`, `limit`.

#### `PATCH /api/admin/enquiries/[id]`
Updates status (`contacted`, `visited`, `approved`, `rejected`) or adds internal remarks.
- **Access:** Authenticated Staff.
- **Request Body:**
  ```json
  {
    "status": "contacted",
    "internal_remarks": "Spoke with candidate. Visiting Branch 1 tomorrow at 11 AM."
  }
  ```

### 2.3 Branches Directory

#### `GET /api/branches`
Lists all five DEVI Hostels branches with floor counts, facilities, address, and live bed vacancy summary.
- **Access:** Public.
