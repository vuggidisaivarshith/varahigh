# 12. UI/UX DESIGN SYSTEM — VARAHI GIRLS HOSTEL

## 1. Brand Identity & Visual Language

DEVI Hostels provides high-comfort, safe, and modern accommodations for college students and RGIA airport staff in Shamshabad. The design system embodies **trust, safety, hospitality, clean modernism, and operational clarity**.

---

## 2. Color Palette & Semantics

| Token | Hex Code | Usage |
|---|---|---|
| **Primary (Imperial Navy)** | `#0f172a` / `#1e293b` | Header navigation, primary buttons, authoritative typography, brand headers. |
| **Accent Gold (Hospitality Gold)** | `#d97706` / `#f59e0b` | Badges, call-to-action highlights, rating stars, premium amenities. |
| **Branch 1-4 Boys (Cobalt Blue)** | `#2563eb` | Male resident tags, Boys branch badges. |
| **Branch 5 Girls (Rose Coral)** | `#e11d48` | Female resident tags, Girls branch high-security enclave badges. |
| **Success (Emerald Green)** | `#059669` | Paid status, vacant bed indicator, admission approved. |
| **Warning (Amber)** | `#d97706` | Approaching due date, pending verification. |
| **Danger (Crimson)** | `#dc2626` | Overdue invoices, occupied beds, rejected enquiries. |
| **Surface Neutral** | `#f8fafc` / `#ffffff` | Page background, cards, clean contrast for readability. |

---

## 3. Typography & Responsive Breakpoints
- **Font Stack:** Geist Sans, Inter, system-ui fallback for high legibility on mobile screens.
- **Breakpoints:**
  - `sm`: 640px (Mobile portrait to landscape)
  - `md`: 768px (Tablets, iPad)
  - `lg`: 1024px (Laptops, small desktops)
  - `xl`: 1280px (Standard desktop displays)
  - `2xl`: 1536px (Large monitors)

---

## 4. UI Components Architecture
- Reusable, accessible components with keyboard navigation support.
- Mobile floating actions: Quick WhatsApp consultation and Direct Call button for Owner E. Bharath Chandra.
- Step-by-step interactive forms with clear validation cues and progress indicators.
